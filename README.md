# TarotMatch

Небольшой шуточный сайт с раскладом на совместимость. Работает полностью в браузере: сервер и Python не нужны.

## Структура

- `index.html` — разметка страницы и поля ввода.
- `style.css` — внешний вид, цвета, адаптация под телефон и анимации.
- `script.js` — логика случайного расклада и особое правило для Арсена.

## Запуск локально

Самый простой вариант — открыть `index.html` в браузере. Для разработки можно запустить локальный HTTP-сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `tarot-match`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Подождите минуту или несколько. Адрес обычно будет таким: `https://ВАШ-ЛОГИН.github.io/tarot-match/`.

Если репозиторий называется `ВАШ-ЛОГИН.github.io`, адрес сайта будет `https://ВАШ-ЛОГИН.github.io/`.

## Как изменить особое правило

Откройте `script.js` и найдите:

```js
const isArsenSpecial = normalizedName === "арсен" && month === "06" && day === "08";
```

Здесь `06` — июнь, `08` — восьмое число. Специальный результат задаётся в блоке `if (isArsenSpecial)`.

## Важно

Сайт не отправляет и не сохраняет введённые данные: всё вычисляется локально в браузере. Расклад носит развлекательный характер.
